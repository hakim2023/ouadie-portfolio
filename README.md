# ouadie.net

Portfolio d'Abdelhakim Ouadie, développeur web fullstack à Paris.

Site statique (HTML, CSS, JavaScript), sans framework ni étape de build. Hébergé sur Netlify ; le formulaire de contact utilise Netlify Forms.

- `index.html` : contenu (projets, compétences, parcours, contact)
- `style.css` : mise en page (thème clair / sombre automatique)
- `main.js` : aperçu des projets au survol, envoi du formulaire
- `assets/` : photo, couvertures des projets, image de partage
